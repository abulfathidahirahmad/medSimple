# medSimple 🩺

> A lightweight, medical MCQ & OSPE study platform built for Paediatrics and Obstetrics & Gynaecology exam preparation.


## 🚀 Overview

**medSimple** is an interactive, zero-dependency medical revision web application. Designed with modern aesthetics and clinical precision, it offers multi-specialty question banks, Computer-Based Test (CBT) navigation, OSPE modules, and real-time performance analytics—all running directly in any browser without requiring a backend server or build pipeline.

---

## ✨ Key Features
- ⚡ **100% Offline Compatible**: Double-click `index.html` to run locally without internet access or local servers.
- 🎯 **Dual Question Engines**:
  - **Single-Best-Answer (SBA)**: Clinical scenarios with comprehensive option explanations.
  - **5-Option Multiple True/False (MTF)**: Individual option evaluation with instant or post-submission feedback.
- 🏥 **Clinical OSPE Modules**: Dedicated station-based practical revision tools.
- 🗂️ **CBT Question Grid**: Interactive palette tracking status (*Unvisited*, *Visited*, *Correct*, *Incorrect*, *Bookmarked*).
- 🔍 **Instant Search & Filters**: Search across question text, options, and explanations with live category filtering.
- 📊 **Performance Analytics**: Visual stats, completion tracking, and category accuracy breakdowns.
- 🌓 **Adaptive UI**: Sleek dark and light mode toggle with local storage persistence.

## 💻 Getting Started

### Local Desktop Usage (Offline)
No installation, Node.js, or server setup required.

1. Clone or download this repository.
2. Double-click [index.html](file:///x:/MCQ--APP/index%20plain/index.html) in your browser.

```bash
git clone https://github.com/SiriusTheCelestial/mcqsPractice.git
```

### GitHub Pages Deployment
1. Navigate to repository **Settings** → **Pages**.
2. Select `main` branch and `/ (root)` folder.
3. Click **Save**. The platform is immediately live online.
